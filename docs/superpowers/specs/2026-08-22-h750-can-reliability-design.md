# H750 CAN 底盘可靠性重构设计

**日期：** 2026-08-22  
**基准：** `zt` 分支 `8a4ea997`  
**目标工程：** `D:\stm32project\26工训\工训H750`

## 目标

在不改变 ZDT X42S CAN 协议和现有控制分层的前提下，使底盘在单台电机丢回复、RX FIFO 堆积、CAN 短暂错误和 Bus-Off 时不会永久卡住采样状态机，并能向导航层提供明确、可追溯的健康状态。

## 保留的边界

- 保留 `devices/motor/zdt_x42s -> control/chassis -> control/localization -> control/heading -> control/navigation -> Core/Src/freertos.c` 分层。
- 保留扩展帧、Classic CAN、1 Mbit/s、`motor_id << 8`、`F6` 速度协议、`36 6B` 位置协议和 `FF 66 6B` 同步帧。
- 不引入动态内存、C++、新的通信协议或未经 HAL 头文件确认的 API。
- 导航层只接收 `motor_ok`、`can_ok` 等健康结果，不承载 CAN 协议细节。

## 设计

### 1. 位置采样状态机

`LocalizationService` 采用 `IDLE -> START BATCH -> WAIT REPLY -> FINISH/ABORT` 状态流。启动批次前先检查 TX FIFO 容量并保存四台电机的序列基线；四个请求必须全部入队成功才进入等待状态。等待状态使用 `POSITION_REPLY_TIMEOUT_MS` 超时退出，记录缺失电机位图并安排下一次重试。旧回复只能通过启动时重新保存的序列基线被排除，不能组成新批次。

完成批次后保留现有同步时间跨度和位置跳变检查，但新增拒绝计数；一次异常采样只丢弃当前批次，连续异常才由上层形成硬故障状态。

### 2. 位置快照一致性

RX ISR 使用每个位置槽的内部写保护序列：写入前标记为更新中，写入 `position/timestamp/valid/sequence` 后发布完成标记。任务侧循环读取前后保护序列，只有两次相同且不处于更新中的快照才复制到调用者。对外暴露的 `ZdtX42sPositionSample.sequence` 仍保持每个合法位置回复递增一次，避免破坏批次基线语义。

### 3. RX 处理和过滤

`HAL_FDCAN_RxFifo0Callback` 只负责排空 FIFO0，并把每帧交给独立解析函数。解析器依次验证扩展数据帧、有效电机 ID、DLC、功能码和尾字节；非法帧不刷新位置、时间戳、序列或有效回复计数，并按原因增加诊断计数。过滤器改为显式设置 ID 范围和全局拒收规则；支持的 HAL 通知则同时开启 FIFO 满和消息丢失诊断。

### 4. 电机在线和 CAN 健康

驱动保存每台电机最近合法回复时间和最近位置回复时间，并由 `ZdtX42s_GetMotorOnlineMask(now_ms)` 根据新鲜度生成位图。`bus_error_count` 仅保留为累计统计；当前状态使用 `OK/WARNING/ERROR_PASSIVE/BUS_OFF` 枚举，并记录各状态次数、最近错误时间和错误码。

Bus-Off 恢复由驱动服务函数处理：恢复后先发送停止命令，再等待四台电机重新在线；导航保持 FAULT，不自动恢复之前的运动命令。若 HAL 版本不提供明确的恢复 API，则只使用该版本头文件中实际存在的能力并在 README 记录限制。

### 5. 底盘输出

麦轮运动学计算后先对四个轮速进行整体比例归一化，再编码为 `int16_t`，保持运动向量比例。速度输入先检查 `isfinite`，非法浮点值直接返回错误，不进入 CAN 命令编码。

## 测试策略

- 定位服务覆盖完整批次、单电机超时、超时后的旧回复、TX 入队失败、采样跨度超限和异常跳变。
- 驱动覆盖合法位置帧、非法 DLC、尾字节、功能码、ID、标准/远程帧、FIFO 多帧排空、快照序列和诊断时间戳。
- 底盘覆盖整体比例限幅和 NaN/Inf 拒绝。
- 每个阶段先运行对应主机单元测试，再运行完整 `verify_software_link.sh`、Debug/Release 配置和构建。
- 实机验证只写入 README，不宣称软件测试替代 CAN 收发器、电机和急停硬件验证。

## 风险和取舍

- 位置快照使用内部保护序列而不是长时间关中断，避免复制结构体期间阻塞 CAN ISR。
- Bus-Off 的具体恢复调用必须以工程内 STM32H7 HAL 头文件为准；没有明确支持时不猜测函数名。
- RX 范围过滤只能缩小到当前电机 ID 范围，协议级解析仍是最终有效性判断。
